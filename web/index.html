PEGA PRIMATA

Pega-pega de macaco: ande só com os braços.

VR: empurre o chão e as paredes com as mãos para se mover. Analógico direito gira (Vive: aperte as laterais do touchpad). B/Y ou clique do analógico esquerdo = renascer.
VR no PC: funciona com SteamVR, Quest Link/Air Link, Virtual Desktop e WMR. Ligue o headset e o jogo detecta sozinho.
PC: WASD = remar com os braços • Mouse = olhar (olhe para cima para escalar) • Espaço = pular • Shift = correr • Clique esq./dir. = tapa • R = renascer • Esc = menu
VR: abra este jogo no navegador do Quest ou pelo APK.

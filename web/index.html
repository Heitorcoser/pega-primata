ESTAÇÃO ZERO

Os babuínos do laboratório escaparam. Ande com os braços, ache as amostras e suba pelos elevadores até a superfície. Eles só enxergam o que está à frente…

Como jogar: encoste a mão nas 3 amostras azuis de cada andar para abrir o elevador de saída. Elevadores são zona segura. Caixas com faixa amarela, prateleiras, tanques e mezaninos ficam fora do alcance dos monstros.
VR: empurre o chão e as paredes com as mãos. Analógico direito gira (Vive: laterais do touchpad). B/Y ou clique do analógico esquerdo = voltar ao elevador.
VR no PC: SteamVR, Quest Link/Air Link, Virtual Desktop e WMR — ligue o headset e o jogo detecta.
PC: WASD = remar com os braços • Mouse = olhar (olhe para cima para escalar) • Espaço = pular • Shift = correr • Clique = tapa/pegar • R = voltar ao elevador • Esc = menu
VR: abra este jogo no navegador do Quest ou pelo APK.
